# Setup

Use Git and Python 3. No third-party packages are needed. In an empty directory, clone the supplied bundle with `git clone repository.bundle queue-demo`. Enter queue-demo and run `python -m unittest discover -s tests -v`. On main the baseline counts open tickets only. Use `git switch --detach origin/rehearsal/integrated` in a disposable clone to test the combined result. Use `git switch main` to return.
