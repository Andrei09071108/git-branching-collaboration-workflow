# Handover

The owner maintains the public main branch. [PR #1](https://github.com/Andrei09071108/git-branching-collaboration-workflow/pull/1) and [PR #2](https://github.com/Andrei09071108/git-branching-collaboration-workflow/pull/2) document the two requirements, self-review and integrations. One author performed the changes and reviews. The independent audit concerned the private rehearsal package.

For future proposals branch from current main, review the diff, run the queue tests and describe any conflict decision in the PR. After a merge, clone main and repeat the [setup checks](setup.md). The baseline bundle and evidence stay with the owner.
